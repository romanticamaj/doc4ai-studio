## 0. Global constraints (copied from spec; apply to every task in every phase)

- Windows 11 host, Python 3.10.11 on host, `uv` 0.10.9, Node 24, pnpm 10, RTX 5070 Ti 16 GB (Blackwell, **sm_120**).
- Main program (`src/aidoc`) is light: PyMuPDF, FastAPI, uvicorn, tiktoken, psutil, nvidia-ml-py and small helpers. **Never install torch in the main env.**
- Engine versions: MinerU **4.0.x** (`--tier basic|standard|advanced`), Docling **2.x** (`docling[easyocr]`), MarkItDown **0.1.8**. Locked by `envs/*/uv.lock`.
- Engine envs: `envs/<engine>/.venv`; venv python is `.venv/Scripts/python.exe` on Windows, `.venv/bin/python` on POSIX.
- torch for sm_120: torch ≥ 2.7 from `https://download.pytorch.org/whl/cu128` (torch ≤ 2.11) via `[[tool.uv.index]] explicit = true` + `[tool.uv.sources]` for `torch` and `torchvision` with marker `sys_platform == 'win32' or sys_platform == 'linux'`. `cu126` and the PyPI CPU wheel are forbidden. Self-check: `torch.cuda.is_available()` AND `"sm_120" in torch.cuda.get_arch_list()`.
- Runner scripts (`src/aidoc/engines/runner/*_runner.py`) import **only stdlib + the engine's own package + the sibling `_proto.py`**; they never import `aidoc`.
- Runner subprocesses are launched with `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`; the host reads stderr with `errors="replace"`.
- MinerU: install `mineru[torch]`, **not** `[full]`; env `MINERU_MODEL_SMALL_BACKEND=torch`, `MINERU_HOME=<data>/models/mineru`; default tier `basic` (§13.1); no language parameter (runner ignores `lang`).
- Docling: `EasyOcrOptions(lang=["ch_tra","en"])` for `cht`, `["en"]` for `en`; `OcrMode.FULL_PAGE` when Docling is the fallback for scanned input; `AcceleratorOptions(device="cuda")`; `settings.perf.page_batch_size` default 16, halve on OOM; `artifacts_path` = `<data>/models/docling`.
- `lang` values are exactly `cht` (default) and `en`; engine-specific codes exist only inside `engines/docling.py`.
- Output layout `out/<stem>/<stem>.md`, `<stem>.json`, `assets/p<page>_<n>.<ext>`; page markers `<!-- page: N -->`; stem sanitised (Windows reserved names, trailing dots/spaces, `<>:"/\|?*`); collision → `<stem>-<sha8>`.
- Atomic output: write to `out/.tmp/<task_id>/`, finalise by rename; existing target → three-step via `out/.trash/<task_id>/`; `PermissionError` on rename/delete → exponential backoff `0.2s × 5`; still failing → `failed(transient)`. Single files: write `.<name>.tmp` then `os.replace`.
- Segments: PDFs > **40** pages are split into 40-page segments (P2). Whole document uses one engine; per-segment quick quality check; any failure → whole document re-run with next fallback.
- Timeouts: per page 60 s, minimum 120 s (segment pages when segmented); page-less formats: 30 s/MB, min 120 s, max 1800 s; `--timeout` overrides; timer starts at the runner's first `AIDOC_READY`/`AIDOC_PROGRESS` line (see §2 below for the resolution of "first progress or log line").
- Retry policy (P2): `transient` → 2 retries, backoff 5 s → 30 s; OOM → Docling halves `page_batch_size`, MinerU downgrades tier `standard → basic`, still OOM → `engine` failure; `engine` → next fallback; `input` → `failed`, no retry.
- Audio is **off** by default (§13.3): `enable_audio=false` / `--allow-online-audio`; disabled → `failed(input: audio_disabled)`.
- `low` results are cache hits (§13.4); `--retry-low` re-converts them.
- Quality thresholds: avg chars/page < 50 (non-PDF: whole doc < 50) → fail; garbage ratio > 5 % → fail; `has_table_lines` and no table in output → fail. Thresholds are initial; tune on fixtures.
- Server (P3) binds `127.0.0.1` by default; `--host 0.0.0.0` requires `--token`, else refuse to start. Local paths in `POST /api/jobs` accepted only from loopback or with a valid token. All responses carry `"workspace": "default"`.
- `data/aidoc.lock` (P3) = `{pid, started_at, host, port, auth}` — **never the token** (security review, P3). While a server holds it, `aidoc convert` and `aidoc batch` forward to it; in-process CLI runs hold `data/cli/<pid>.lock` and `aidoc serve` refuses to start next to one (one queue owner, §8.1). Token sources, for `aidoc serve` and for the CLI forwarding to it (`batch`, `cancel`): `--token`, else env `AIDOC_TOKEN`, else `aidoc.toml` `server.token`.
- Uploads: 8 MB chunks, `PUT /api/uploads/{id}?offset=N` only accepted when `offset == received`; `HEAD` returns `Upload-Offset`; sha256 verified on completion; 2 GB default limit; unfinished uploads purged after 24 h; free disk must be ≥ 3 × input size.
- Work copies retained 7 days after success (`work_retention_days`).
- **2026-10-05 VLM:** `vlm` engine: `vlm_runner.py` runs on the host interpreter (stdlib + pymupdf); the local runtime is a pinned llama.cpp prebuilt under `envs/vlm/llamacpp/<tag>/` (plan deviation: the plan said `data/tools/llamacpp/`) plus GGUF files under `data/models/vlm/`; `envs/vlm/` holds `manifest.json`, `.ready` and the llama.cpp build (no `.venv` unless spike S1 selects the transformers path).
- **2026-10-05 VLM:** VLM is the last engine of every PDF/image route and the last repair engine; `backend = "none"` is the default and changes nothing.

## 2. Spec ambiguities resolved here (binding for all phases)

| # | Ambiguity | Resolution |
|---|---|---|
| A1 | §8.8 "timer starts at first progress **or log** line" — library logs during model load would start the clock too early. | Timer starts at the first `AIDOC_READY` or `AIDOC_PROGRESS` line from the runner. A separate hard **startup cap** of 900 s applies before that (no AIDOC line in 900 s → `transient` timeout). |
| A2 | Docling per-page export + referenced images: `export_to_markdown(page_no=n)` with `ImageRefMode.REFERENCED` behaviour is unverified. | Runner uses per-page `export_to_markdown(page_no=n)` with the default PLACEHOLDER mode (pictures render as `<!-- image -->`) and saves each `PictureItem` on that page itself via `pic.get_image(doc).save(...)`, then replaces the k-th `<!-- image -->` on that page with `![](<file>)`. P1 spike task verifies no duplicated text across pages. |
| A3 | MinerU 4.x exact `ParseResult.save(writer)` signature unknown at plan time. | P1 spike task runs `inspect.signature` inside the MinerU env and adapts the runner; the **contract** is the produced files `markdown.md`, `middle_json.json`, `structured_content.json`, `images/`. |
| A4 | Spec lists no endpoint for editing `aidoc.toml` from Web Settings. | P3 adds `GET /api/settings` and `PUT /api/settings` (whitelisted keys). |
| A5 | `jobs.status` values not enumerated. | `queued` / `running` / `done` / `cancelled`. `done` when every task is terminal (`done|low|failed|skipped|cancelled`). |
| A6 | IDs. | All ids are `uuid4().hex` TEXT. `events.seq` is INTEGER autoincrement. |
| A7 | Segment table image prefix vs. normalised names. | Normalised asset names use the absolute page number `p<page>_<n>`, which is already unique across segments; images with unknown page use `s<seg_idx>_<n>`. |
| A8 | Where per-segment normalisation happens. | Each segment is normalised independently with `page_offset = page_start - 1`; merge concatenates normalised markdown and moves assets. |
| A9 | Fake engine for tests. | `AIDOC_FAKE_ENGINES=1` makes `registry.get_engines()` return three `FakeEngine`s named `markitdown`, `docling`, `mineru`, all backed by `fake_runner.py` (a real subprocess, so kill/timeout tests are honest). Behaviour is scripted by a JSON scenario file at `AIDOC_FAKE_SCENARIO` (§6). |
| A10 | CLI when server is running (§8.1) is a P3 feature; P1/P2 CLI runs the queue in-process. | P1/P2 `batch` runs in-process. P3 adds forwarding when a live `aidoc.lock` belongs to a server. |
| A11 | `documents` row for `low` results. | `documents.status = "low"`; still listed in Library; cache hit unless `--retry-low`. |
| A12 | Main program Python version. | `requires-python = ">=3.10"`; use `tomli` on < 3.11 (`tomllib` otherwise), `tomli-w` for writing (P4: replaced by `tomlkit`, which keeps comments). |
| A13 | §8.7 says hashing runs "in parallel with the upload", but `POST /uploads` requires `sha256` up front (the server needs it to verify). | The Web Worker hashes the file first (streaming, flat memory), then the upload starts. On a local network the hash pass is a small fraction of upload time; resume behaviour is unaffected. Contract in §8 stays. |
| A14 | §5 says re-running a batch reuses unfinished tasks; §8.2 says a cancelled task's finished segments must survive a retry. What counts as "unfinished"? | `Store.create_task` reuses an existing `(sha256, output_dir)` row whose status is `queued|probing|converting|checking|failed|cancelled` (segments kept, status reset to `queued`); `done|low|skipped` rows are replaced by a new row. (P2 Task 8 changes the P1 rule.) |
| A15 | `aidoc batch <dir>` — recursive or not? | Recursive, sorted, skipping hidden entries and the ignore list; output dirs are flat under `-o` (collisions get `-<sha8>`). |
| A16 | §8.4 "pause waits for the current segment to finish". | Pipeline accepts a `pause` event checked between segments (and between tasks by the queue); cancel still interrupts immediately. |
| A17 | §8.5 "orphaned when listing documents" without an explicit trigger. | Orphan marking runs at startup (recovery step 4) and on `POST /api/documents/rescan` (Library 「重新掃描」). |
| A18 | `POST /tasks/{id}/retry` for a `done|low|skipped` task would hit the cache. | Retry sets `tasks.flags_json = {"force": true}` (schema v2) so the pipeline bypasses the cache for that run only. P4: `retry_low: true` also sets `auto_engine: true`, so 「重轉低品質」 lets routing choose the engine even when the job forced one (flags are cleared when the run ends). |
| A19 | Spec 2026-10-01 adds a third quality level. | `QualityResult.level ∈ {"ok","warn","low"}`. `warn` = usable with known problem pages: no fallback, task status `done`, cache hit like `ok` (not affected by `--retry-low`), `documents.status = "warn"`. Level rules: spec 2026-10-01 §5.2. |
| A20 | Page boundaries. | Runners produce page markers from engine structure only (spec 2026-10-01 §6); no text search. `result.json` gains `page_map_method` (`mineru_render_plan` / `mineru_single_page` / `docling_per_page` / `markitdown_per_page` / `none`). |
| A21 | Where does the VLM sit? | Always last in routing (after MarkItDown for `pdf_default`) and last in repair. Never before a cheaper engine. Spec 2026-10-05 VLM §5–§6. |
| A22 | Remote VLM privacy. | `remote_enabled` defaults to false; loopback `base_url` is "local" (info, not warning) but still needs the switch; every remote use logs `vlm(openai): sending N page image(s) to <host>`; sidecar records `vlm.endpoint_host` and `pages_sent`; keys only via env (`api_key_env`) or masked config. |
| A23 | Segment reuse across VLM models. | `options_key()` includes `vlm_backend` and `vlm_model`; `vlm_remote` is not part of it. |

## 3. Shared types — `src/aidoc/models.py` (P1 creates; later phases only add, never rename)

```python
from __future__ import annotations
from dataclasses import dataclass, field, asdict
from enum import Enum
from pathlib import Path
from typing import Literal, Callable

Lang = Literal["cht", "en"]
ENGINE_NAMES = ("markitdown", "docling", "mineru")
SEGMENT_PAGES = 40

class TaskStatus(str, Enum):
    queued = "queued"; probing = "probing"; converting = "converting"; checking = "checking"
    done = "done"; low = "low"; failed = "failed"; skipped = "skipped"; cancelled = "cancelled"
TERMINAL_TASK = {TaskStatus.done, TaskStatus.low, TaskStatus.failed, TaskStatus.skipped, TaskStatus.cancelled}

class SegmentStatus(str, Enum):
    queued = "queued"; converting = "converting"; done = "done"; failed = "failed"

class JobStatus(str, Enum):
    queued = "queued"; running = "running"; done = "done"; cancelled = "cancelled"

class ErrorKind(str, Enum):
    transient = "transient"; engine = "engine"; input = "input"

class DocStatus(str, Enum):
    ok = "ok"; warn = "warn"; low = "low"; orphaned = "orphaned"     # warn: spec 2026-10-01 (A19)

InputKind = Literal["pdf", "image", "office", "html", "audio", "other"]

@dataclass
class ConvertOptions:
    output_dir: Path
    engine: str | None = None          # forced engine, no fallback
    lang: Lang = "cht"
    force: bool = False
    retry_low: bool = False
    timeout_s: int | None = None
    allow_online_audio: bool = False
    mineru_tier: str = "basic"         # "basic" | "standard"
    docling_ocr: str = "easyocr"       # "easyocr" | "rapidocr" (decided by P1 spike)
    def to_json(self) -> dict: ...     # Path -> str
    @classmethod
    def from_json(cls, d: dict) -> "ConvertOptions": ...

@dataclass
class ProbeResult:
    kind: InputKind
    ext: str                           # lower-case, with dot: ".pdf"
    size: int
    pages: int | None = None           # PDFs only
    text_ratio: float = 0.0
    image_cover: float = 0.0
    math_hint: bool = False
    layout_hint: bool = False
    has_table_lines: bool = False
    blank_pages: list[int] = field(default_factory=list)   # 1-based
    error: str | None = None           # "corrupt" | "encrypted" | None
    broken_fonts: list[str] = []       # 2026-10-01: Type0/Identity fonts without /ToUnicode (names, no subset prefix)
    broken_font_pages: list[int] = []  # 2026-10-01: 1-based, all pages scanned
    def to_json(self) -> dict: ...     # emits broken_fonts and broken_font_pages_count instead of the page list

@dataclass
class RouteDecision:
    engines: list[str]                 # primary first, then fallbacks
    reason: str                        # human readable rule name, e.g. "pdf_scanned"
    forced: bool = False

@dataclass
class TableEdge:
    page: int                          # page within the segment's *own* PDF (1-based)
    n_cols: int
    touches_edge: bool                 # first table: touches top; last table: touches bottom

@dataclass
class RawResult:
    markdown: str                      # may already contain <!-- page: N --> (N relative to the segment PDF, 1-based)
    image_paths: list[Path]
    raw_dir: Path
    has_page_markers: bool
    page_count: int | None = None
    first_table: TableEdge | None = None
    last_table: TableEdge | None = None
    page_map_method: str | None = None # 2026-10-01 (A20)

@dataclass
class NormalizedResult:
    markdown: str                      # page markers rewritten to absolute pages, images -> assets/<name>
    assets: list[tuple[Path, str]]     # (source file, name under assets/)

@dataclass
class QualityResult:
    score: float                       # 0..1
    level: Literal["ok", "warn", "low"]                     # warn: 2026-10-01 (A19)
    reasons: list[str]                 # "chars_per_page", "garbage_ratio", "missing_table"; 2026-10-01 adds
                                       # "page_map_incomplete", "page_map_misaligned", "pages_flagged"
    metrics: dict = field(default_factory=dict)
    page_check: int | None = None      # 2026-10-01: per-page assessment version
    page_map: dict | None = None       # 2026-10-01: PDFs only
    pages: list[dict] = []             # 2026-10-01: flagged pages; page-level reasons "page_map_missing",
                                       # "broken_text_layer", "garbage"; optional "repaired_by"
    pages_flagged: int = 0             # 2026-10-01: flagged before repair
    def to_json(self) -> dict: ...     # adds page_check, page_map, pages, pages_flagged, pages_unrepaired
                                       # (= entries without repaired_by) only when page_check is not None

@dataclass
class Attempt:                         # one entry of tasks.tried_json
    engine: str
    attempt: int
    score: float | None
    reasons: list[str]
    error_kind: str | None = None
    error_msg: str | None = None

ProgressCb = Callable[[float, str], None]   # (fraction 0..1 within the segment, log line)
```

## 5. Runner protocol (P1 defines; P2 uses multi-request mode; never changes shape)

Host launches `venv_python(engine) <runner_script>` with cwd = workdir, env = os.environ + `PYTHONUTF8=1 PYTHONIOENCODING=utf-8 MINERU_HOME=<data>/models/mineru MINERU_MODEL_SMALL_BACKEND=torch HF_HOME=<data>/models/hf EASYOCR_MODULE_PATH=<data>/models/easyocr AIDOC_MODELS_DIR=<data>/models`.

- **stdin**: one line per request: the absolute path of a `request.json`. EOF → runner exits 0.
- `request.json`:
  ```json
  {"src": "C:/.../seg_0.pdf", "out_dir": "C:/.../seg_0/raw", "lang": "cht",
   "engine_opts": {"tier": "basic", "page_batch_size": 16, "ocr": "easyocr", "full_page_ocr": false, "allow_online_audio": false},
   "kind": "pdf"}
  ```
- **stderr** lines (UTF-8, one JSON object per line after a prefix; anything else is a log line):
  - `AIDOC_READY {}` — models loaded, ready for first request (emitted once, before reading stdin).
  - `AIDOC_PROGRESS {"page": 12, "total": 40}` — optional, any frequency.
  - `AIDOC_DONE {"request": "<request.json path>", "result": "<result.json path>"}`
  - `AIDOC_ERROR {"request": "<path>", "kind": "engine|input|transient", "message": "..."}` — runner stays alive for the next request.
- `result.json`:
  ```json
  {"markdown_path": "C:/.../raw/out.md", "images": ["C:/.../raw/images/a.png"], "has_page_markers": true,
   "page_count": 40, "first_table": {"page": 1, "n_cols": 3, "touches_edge": false} , "last_table": null}
  ```
- 2026-10-01: request `engine_opts` may carry `backend: "docling_parse" | "pypdfium"` (Docling) and `ocr_mode: "auto" | "ocr" | "txt"` (MinerU); `result.json` gains `page_map_method` (A20).
- 2026-10-05 VLM: `engine_opts` for `vlm` (spec §4.2 two shapes); `result.json` may carry `vlm: {backend, model, endpoint_host, pages_sent, usage, truncated_pages, refused_pages, dpi, prompt_version}`; `page_map_method` enum gains `vlm_per_page`; runner env may carry `AIDOC_VLM_API_KEY_INLINE` (host-injected, never in request.json).
- Exit code ≠ 0 or process death → host raises `EngineError(transient)`; if stderr tail contains `CUDA out of memory` or `OutOfMemoryError` → `EngineError(transient, oom=True)`.

`_proto.py` (stdlib only) gives runners `serve(handle: Callable[[dict], dict])` that implements the loop, plus `progress(page, total)` and `log(msg)`.

**§8 as implemented in P3 (additive only — every row above holds; P4 may rely on these extras):**
- Every error body is `{error: "<code>", ...extra, workspace}`; 404 → `not_found`, 422 validation → `validation_error` (+ `detail`), token missing/wrong → 401 `unauthorized`. Token = `Authorization: Bearer <t>` or `?token=<t>` (use `?token=` for `EventSource`). Without a token the server answers `/api` only for loopback `Host` names (else 403 `bad_host`, DNS-rebinding guard), and a non-GET request carrying an `Origin` must be same-origin (else 403 `cross_origin`) — the P4 dev proxy must forward to `127.0.0.1`/`localhost` and keep same-origin requests.
- `POST /jobs` also accepts `origin: "web"|"cli"` (default `web`), `output_dir` (local path; same loopback/token rule as `path` inputs, else 403 `local_path_forbidden`) and `timeout_s`. Errors: 400 `input_not_found {path}`, 404 `upload_not_found {upload_id}`, 409 `upload_incomplete {upload_id, received, size}` (also for a consumed upload), 409 `already_converting`, 507 `insufficient_disk {needed, free}`. `201 {job}`; `task.updated` for each new task and `job.updated` are published before the response.
- `POST /uploads` errors: 413 `upload_too_large {limit}`, 507 `insufficient_disk {needed, free}` (3 × size); `422` for a non-hex sha256. `PUT` errors: 409 `bad_offset {received}`, 409 `upload_not_receiving {status, received}`, 413 `chunk_too_large {chunk_size}`, 400 `exceeds_declared_size`, 422 `sha_mismatch` (file deleted, upload `failed`), 404. `PUT` 200 body is `{received, status}` (`receiving|complete`). `HEAD` also sends `Upload-Status`. Extra: `GET /uploads/{id}` → `{upload: {id, filename, size, sha256, received, status, created_at}}`. The filename is reduced to its last path component.
- `POST /tasks/{id}/retry`: 404 unknown, 409 `task_running`, 409 `not_a_local_source` (use_new_version on an uploaded file), 410 `source_missing {path}`. A retried done/low/skipped task starts over (segments reset, `flags.force` for that one run); failed/cancelled tasks resume their done segments; retrying a task of a cancelled job re-opens the job.
- `POST /queue/pause|resume` → `{queue: {paused, length, running_task_id}}` (same object as `/system` `queue`). Pause lets the running *segment* finish, then the task goes back to `queued` (done segments kept).
- `POST /jobs/{id}/cancel`: queued tasks → `cancelled`, the running one is interrupted (runner killed); job status `cancelled` is sticky until one of its tasks is retried.
- Task objects also carry `flags`, `work_path`, `mtime`; `pages` / `document_id` are null until a document exists. For an uploaded file `source_path` is the display filename (not a path).
- `GET /documents/{id}` also returns `sidecar` (the `<stem>.json` content or null). `markdown` / `download.zip` → 410 `output_missing` when the output dir is gone. Assets: 400 `bad_path` for traversal/absolute/drive paths. `source` serves the retained work copy (`src.*`) first, else the original local file; 410 `source_missing`. `POST /documents/rescan` also restores `orphaned` rows whose output is back (to their quality level).
- `POST /chunks`: `max_tokens` 1..100000 (422 otherwise); 409 `output_missing`; 503 `tokenizer_unavailable` when cl100k_base is not cached and cannot be downloaded. Chunk `source` is the source file *name*.
- `GET /system`: `engines.<name>` = `{installed, ready}` plus `checked_at`, `cuda`, `version`, `torch`, `device` when the `.ready` marker has them; `disk_free` may be null. `POST /system/setup/{engine}`: 404 `unknown_engine`, 409 `setup_running {setup_id, engine}`; `202 {setup_id, engine}`.
- `PUT /settings`: 422 `invalid_settings {detail}` for unknown section/key, wrong JSON type (bools are not ints), bad enum (`lang`, `mineru_tier`, `docling_ocr`) or negative numbers; 403 `token_readonly`; `settings.server.token` reads `"***"` when a token is set. Saved values apply immediately (host/port on the next start). Saving keeps `aidoc.toml`'s comments and layout (tomlkit, P4 Task 0).
- **P4 Task 0 (P3 final-review minors):** `POST /jobs` with the same `upload_id` twice → 400 `duplicate_input {upload_id}` (nothing is created). `POST /jobs/{id}/cancel` on a job that is already `done` or `cancelled` is a no-op: 200 with the unchanged job. `POST /system/setup/{engine}` → 409 `engine_busy {engine, task_id}` while the running task uses that engine (or has not chosen one yet; `all` conflicts with any running task). `?token=` is shown as `token=***` in the uvicorn access log.
- **P4 (verifier findings):** 409 `upload_not_receiving` for a PUT to a finished upload (was 500); `download.zip` uses `filename*=UTF-8''…`; a `path` input may be a folder (expanded like `aidoc batch`; empty → 400 `no_inputs`) and must be absolute (400 `path_not_absolute`); `PUT /settings`: `server.*` is read-only (403 `server_readonly`, unchanged values ignored), a masked/unchanged token is ignored, ranges enforced (port 1–65535, disk_space_factor 1–100000, upload_max_bytes ≤ 1 TiB, no UNC output_dir); `GET` on a POST-only `/api` path → 405 `method_not_allowed`; `/api/docs` only without a token; non-`/api` routes check `Host` too; SSE `data` carries `workspace`; a `Last-Event-ID` above the newest event → `resync`.
- **P4 final round:** `/documents/{id}/source` and `/assets/*` are inline only for PDF and raster images, else `attachment` + `application/octet-stream`; every file response has `nosniff` and `CSP: sandbox; default-src 'none'`; SPA pages carry a CSP. `PUT /uploads` → 507 `disk_full` / 500 `upload_write_failed` (nothing counted). `POST /jobs`: a duplicate input becomes a `skipped` task with `error_msg: "duplicate_of: …"`; UNC `path`/`output_dir` → 422 `unc_path_forbidden`; a busy upload → 409 `already_converting {task_id, upload_id}` before anything is created. `PUT /settings` writes only changed keys.
- **2026-10-01 (per-page quality and page map):** `GET /documents?flag=page_map_incomplete|page_quality|unassessed`, `status=warn`; Document gains `flags: string[]`, `page_summary: {expected, found, coverage, flagged, unrepaired} | null`; `POST /documents/rescan` → `{orphaned, assessed, page_map_incomplete, page_quality}` (`?all=1` re-assesses everything); `POST /documents/reconvert {ids}` → `201 {job}` | `404 not_found {id}` | `410 source_missing {id}` | `409 already_converting {id, task_id}` | `422 validation_error` (0 or > 500 ids).
